Knee MRI ACL Decision Support Framework

Automated multi-architecture deep learning system for sagittal knee MRI classification across healthy, partial tear, and complete rupture cases. Incorporates deterministic volume slice sampling, cross-model consensus, and genuine Grad-CAM interpretability grounded in radiologic features.

Evaluated models & training controls

  • ResNet-18: 18-layer residual network fine-tuned on single-channel knee MRI slices with ImageNet initialization and weighted cross-entropy. (Note: The presentation deck listed ResNet-50; the actual trained checkpoint deployed in this repository is ResNet-18.)
  • DenseNet-121: Dense feature connectivity maximizing gradient flow across deep convolutional blocks, specialized for subtle interstitial tear patterns.
  • EfficientNet-B0: Compound depth/width scaled convolutional architecture providing compact, high-precision spatial representation.
Verified training controls used in training code:
  • Dropout: 0.35 applied before linear classification heads.
  • Weight decay: 1e-4 with Adam optimizer.
  • Batch normalization: Included natively within convolutional backbones.
  • Early stopping: 7-epoch patience monitoring validation loss and macro-F1.
