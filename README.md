# Knee MRI ACL Classification (Academic Project)

Student research project for classifying ACL condition from annotated knee MRI
regions. The repository contains a feature-based baseline, image preprocessing,
CNN training and evaluation, simulated recovery-sequence modeling, and a
structured report demo.

Read the [project guide](PROJECT_GUIDE.md) for setup, run commands, module
descriptions, expected outputs, evaluation interpretation, and limitations.

The MRI dataset, local virtual environment, preprocessing caches, and trained
model artifacts are excluded from Git. Download the KneeMRI dataset separately
and place it under `data/KneeMRI/` before running the project. The source data
has a non-commercial, no-derivatives license; see the guide for attribution.

This project is for education and research. It is not a clinical diagnostic
tool.
